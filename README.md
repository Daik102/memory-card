<h1>Project: Memory Card</h1>

A memory card game app with several features<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Rendering beautiful images from <a href="https://unsplash.com/developers">Unsplash API</a> using useEffect

- Fisher-Yates shuffle algorithm for efficient deck randomization

- A bonus animation when a player completes the deck

- Responsive Design implemented

<h3>Tech Stack</h3>

- Frontend: React, CSS, JavaScript

- Build Tool: Vite
